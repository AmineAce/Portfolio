## The Problem

Modern blogging often comes with unnecessary complexity — JavaScript-heavy frameworks, database backends, and third-party platforms that control your content and presentation. I wanted a personal space to write and share without dependency bloat or platform lock-in. Every extra kilobyte of JavaScript is a barrier between the reader and the content.

## What I Built

Blog Hub is a personal blog built entirely with semantic HTML and hand-written CSS. No frameworks, no build tools, no JavaScript runtime dependencies. The focus is on content-first design: clean typography, responsive layout, fast load times, and complete control over every pixel. The site achieves perfect Lighthouse scores by default because there's nothing to optimize — no JavaScript to parse, no fonts to load, no frameworks to bootstrap. Just content, styled intentionally.

## What I Learned

Building without a framework revealed how much modern tooling abstracts away. I gained a deeper appreciation for semantic HTML structure, CSS layout fundamentals, and the performance budget that frameworks consume before rendering a single word of content. The biggest insight was that "static" doesn't mean "simple" — a well-structured HTML document with thoughtful CSS is often more maintainable and performant than a framework-powered equivalent.
